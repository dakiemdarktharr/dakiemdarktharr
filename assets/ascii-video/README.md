# Profile ASCII showcase

Converted from `profile_github.mp4`, supplied by the repository owner, using
[ascii-video-cpp](https://github.com/dakiemdarktharr/ascii-video-cpp).

- Full ASCII output: 948 frames, 30 FPS, 31.6 seconds, 768×432 pixels.
- Conversion: 96 columns, default charset/brightness/contrast, green text, 4 workers.
- Preview: first 6 seconds, 8 FPS, 576-pixel width, 64-color GIF palette.
- The converted video is silent; the source audio is not included.

The animation and characters belong to their respective creators. These demonstration files
do not grant rights to the underlying animation. The original input file is not included.
